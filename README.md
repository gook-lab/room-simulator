# Roomcast

3D 인테리어 배치 도구 — 평면도를 그리거나 업로드해 가구를 배치하고, 1인칭 워크스루와
조감도로 확인하는 웹 앱. `design_handoff_3d_interior_planner` 핸드오프(1a–1h)의 구현체.

## 실행

```bash
npm install
npm run dev      # 개발 서버
npm run build    # tsc + vite build
npm test         # vitest (순수 로직 테스트)
```

데스크톱 1440×900 기준, 반응형 없음. 백엔드 없음 — 도면은 localStorage에 저장.

## 화면

| 화면 | 진입 |
|---|---|
| 2D 평면도 에디터 (1a) | 기본 화면. 벽/문/창/치수 도구, 가구 카탈로그·인스펙터 |
| 3D 워크스루 (1d) | 뷰 탭 "3D 워크스루". 클릭해 포인터 락 → WASD 이동, E 응시 편집, P 스크린샷 |
| 조감도 (1f) | 뷰 탭 "조감도". 조명 시뮬레이션·표시 토글·카메라 프리셋 |
| 대시보드 (1h) | 로고 클릭 또는 "견적 보기". 도면 카드·견적 요약·공유 |
| 업로드 트레이싱 (1g) | 대시보드 "새 도면 만들기". 업로드 → 스케일 → 수동 트레이싱 |
