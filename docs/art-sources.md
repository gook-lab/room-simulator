## 표지 — 평면도가 3D 모형으로 바뀌는 25평 아파트 (2026-11-25)

- 도구: Codex 이미지 생성(`codex exec --skip-git-repo-check --cd <작업 폴더> --sandbox workspace-write "<프롬프트>" -i <참고> < /dev/null`, codex-cli 0.169.0). 레포 밖 작업 폴더에서 만들었습니다.
- 참고 그림: 앱의 25평 템플릿 2D 에디터 화면에서 평면 부분만 잘라 낸 캡처(1440×900 화면에서 807×617). 방 배치 · 가구 위치 · 색만 참고했습니다.
- 프롬프트 요지:
  - 16:9 구도입니다. 참고 평면과 같은 집을 벽을 가슴 높이에서 자른 아이소메트릭 3D 모형으로 그리고, 왼쪽 가장자리에서 평면 선화로 자연스럽게 돌아가게 했습니다(2D → 3D).
  - 남쪽 창으로 늦은 오후 햇빛이 들고, 무광 점토 질감의 건축 시각화입니다.
  - 색은 앱 토큰(바탕 `#f7f4ef`, 벽 윗면 `#17201c`, 강조 `#0e9f6e`)에 맞췄습니다.
  - 글자 · 숫자 · 로고 · UI · 사람은 없습니다. 실제 브랜드 가구는 흉내 내지 않았습니다.
- 생성 결과: 두 장을 만들었습니다. v1 은 거의 위에서 내려다본 시점이라 입체감이 약해 버렸습니다. v2 는 카메라를 돌리고 40° 로 내려 벽 안쪽 면 · 가구 옆면이 보이게 고친 것이고, 이것을 채택했습니다. 원본은 1672 × 941 입니다.
- 확인: 원본 전체와 네 모서리를 직접 보았습니다. 글자 · 서명 · 로고는 없었습니다.
- 처리: 결정적 변환입니다(Pillow LANCZOS).
