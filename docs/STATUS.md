## Questions (합리적 가정으로 진행 중)

- **React 버전**: Vite 스캐폴드는 React 19였으나 지시대로 React 18.3으로 고정.
  r3f는 v8, drei는 v9 (React 18 호환 최종 메이저), three는 drei 9 peer 범위인 0.170.
- **룸 면적**: 핸드오프의 룸 라벨 값(거실 31.2㎡ 등)은 도면 지오메트리와 불일치
  (합계도 84㎡와 안 맞음). 지오메트리에서 shoelace로 **자동 계산한 실제 값**을 표기함.
- **Room 타입**: README 타입에 `polygon` 필드를 추가(렌더·판정용). ARCHITECTURE.md 참조.
- **상태관리**: README에 라이브러리 지정이 없어 zustand 채택 (r3f 표준 조합).

- **치수 도구**: Plan 타입에 치수 주석 필드가 없어(README 준수) 치수 도구는
  드래그 측정(비영속) + 도면 외곽 자동 치수선으로 구현. 영속 치수 주석은 후속 과제.
- **1c-4 "42cm 겹침" 수치**: 겹침 깊이 계산 대신 겹친 가구명 표기로 대체.
